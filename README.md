
开发人员：执笔梦星云、小伍、老默
出品组织：Quntec——群星云(cloud.quntec.cn)
一个用 Python 做的视觉识别系统，打开摄像头就能实时识别画面中的常见物体（人、车、猫、狗、手机、杯子等 80 类），并在画面上自动标注**边界框 + 物体名称 + 置信度**。
每行代码都有详细中文注释，适合零基础新手学习。

---

## 一、效果说明

程序运行后会：

1. 自动打开摄像头
2. 实时识别画面中的物体
3. 在每个物体上画框，标注名称和把握程度（如 `person 95%`）
4. 左上角显示 FPS（流畅度）和检测到的物体数量
5. 按 `q` 退出，按 `s` 保存当前画面截图

## 三、安装步骤（Windows，跟着做）

### 第 1 步：安装 Python

1. 打开 https://www.python.org/downloads/ 下载最新 Python（推荐 3.11）
2. 双击安装包，**务必勾选 "Add Python to PATH"**（把 Python 加到环境变量），再点 Install Now
3. 安装完成后，按 `Win + R`，输入 `cmd` 回车打开命令行
4. 输入下面命令，看到版本号说明安装成功：
   ```
   python --version
   ```

### 第 2 步：安装依赖库

1. 在命令行里，先用 `cd` 命令进入项目文件夹。例如文件放在 D 盘的 `ai` 文件夹：
   ```
   cd /d D:\ai
   ```
   （把 `D:\ai` 换成你实际的文件夹路径）
2. 安装依赖（这一步会联网下载，可能要等几分钟）：
   ```
   pip install -r requirements.txt
   ```
3. 如果下载很慢，可以换国内镜像加速：
   ```
   pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
   ```
4. 安装完成后，验证是否成功：
   ```
   python -c "import cv2; from ultralytics import YOLO; print('安装成功！')"
   ```
   看到 `安装成功！` 就可以进入下一步。

## 四、运行方法

1. 确保摄像头没被其他程序（微信、Zoom 等）占用
2. 在项目文件夹的命令行里运行：
   ```
   python main.py
   ```
3. 首次运行会自动下载 `yolov8n.pt` 模型文件（约 6MB），下载完会弹出摄像头窗口
4. 对准物体即可看到识别和标注效果

## 七、如何自定义（新手进阶）

打开 `main.py`，找到 **第 2 部分：参数配置**，按注释修改即可：

| 想做的事 | 修改方法 |
|----------|----------|
| 换外接摄像头 | 把 `CAMERA_INDEX = 0` 改成 `CAMERA_INDEX = 1` |
| 让识别更严格（少误报） | 把 `CONF_THRESHOLD` 调高，如 `0.7` |
| 让识别更敏感（多识别） | 把 `CONF_THRESHOLD` 调低，如 `0.3` |
| 用更准的模型（更慢） | 把 `MODEL_FILE` 改成 `"yolov8s.pt"` 或 `"yolov8m.pt"` |
| 改框的颜色 | 修改第 6.3 部分里的 `color` 计算公式 |

## 八、常见问题

**Q1：报错 `无法打开摄像头`**
- 关闭占用摄像头的程序（微信视频、Zoom、其他相机软件）
- 笔记本检查是否有物理摄像头开关/遮罩
- 把 `CAMERA_INDEX = 0` 改成 `1` 试试

**Q2：报错 `No module named 'ultralytics'` 或 `No module named 'cv2'`**
- 依赖没装好，重新执行第 3 步的安装命令
- 确认命令行已经 `cd` 到项目文件夹

**Q3：画面卡顿、FPS 很低**
- 这是 CPU 运行，正常现象。笔记本一般能到 10~30 FPS
- 想更快，可以安装 CUDA 版 PyTorch 调用显卡（进阶，新手先不用管）

**Q4：模型下载失败/很慢**
- 首次运行需联网下载模型。可挂代理或多次重试
- 也可手动从 https://github.com/ultralytics/assets/releases 下载 `yolov8n.pt` 放到项目文件夹里

**Q5：中文路径导致报错**
- 把项目文件夹放到**纯英文路径**下，如 `D:\projects\vision`，避免中文和空格
